# LyriStage

**让歌词站上舞台。**

以歌词为主角的音乐播放器，支持 Windows、Android 和 iPhone。<br>
九种全屏歌词舞台、按你口味每天更新的推荐，还能开房间和朋友同一秒听同一句。

## 功能

- **九种歌词舞台**：唱到哪个字就亮哪个字，每句下面有翻译（中文，或机器翻译的英文），日文、韩文歌还有罗马音。播放中随时切换风格，看歌词时屏幕不会自己暗掉。
- **歌词分享卡片**：选 1 到 4 句，用封面颜色做成限动尺寸的图片。
- **用歌词找歌**：只记得一句歌词也搜得到。
- **每日推荐、私人 FM**：每天早上一份新歌单，由 LyriStage 自己的推荐算法根据你的听歌记录挑选。FM 按「不喜欢」以后就少推荐这类歌。不需要网易云账号。
- **听歌报告、年度回顾**：这个月、今年听了多久、最常听的歌和歌手；年度回顾像限时动态一样一页一页看，有年度歌曲、今年最常听到的一句歌词，每页都能做成图片分享。
- **相似歌曲电台**：从任何一首歌开始，接着播相似的歌，按你的口味排。
- **一起听**：开一个房间，把六位房间码发给朋友，大家同一时间听同一首，房间里就看得到歌词。可以语音（Android 关掉屏幕也继续）、聊天、送表情、点歌给房主，房主也能把房间交给别人。音乐和语音的音量分开调，有人讲话时音乐自动变小。播放由房主控制，成员点歌单里的歌会问要不要点给房主。好友看得到你在一起听，可以请求加入，你同意了才进得来。
- **好友**：独立的好友分页。搜名字或用好友码加好友（要对方同意），好友在听什么会变成头像上的泡泡，颜色跟着那首歌的封面；可以写便签（一句话，可以附上正在听的歌），好友看得到 24 小时，也能用任何表情回应。好友周榜比一比这周谁听最久、各自最常听的歌手。随时可以关掉分享或开私人模式。
- **共同歌单**：邀请朋友一起加歌，每首歌会显示是谁加的。歌单可以换成自己的封面照片，也能做成海报分享。
- **播放队列、睡眠定时**：下一首播放、加入队列、拖动排序，也能把整个队列看成一面封面海报墙，还能做成图片分享；15 / 30 / 60 分钟后或这首播完就停。
- **均衡器**：10 段均衡器和预设，还有音量平衡，每首歌差不多一样大声。
- **自己的音乐库**：我喜欢、歌单、听歌记录、个人名字和头像，电脑和手机同步；换一台设备打开，可以接着听刚才那首。网易云歌单、专辑、每日推荐都能存成自己的歌单。移除歌、取消喜欢都可以复原；忘记密码用邮件里的验证码重设；在设置页可以导出资料、删除账号。
- **Windows**：托盘、最小化时的桌面歌词、任务栏缩图上的播放按钮和右键快捷选单、全局快捷键、开机自动启动、自动更新、首页的 3D 公仔。
- **Android**：离线听歌（自己选要存到手机的歌或整个歌单；存好的歌单会跟着更新，没网络时只播存好的歌）、App 关着也收得到通知（好友回应、好友邀请、有人想加入你的房间，附朋友头像）、后台播放、锁屏和通知栏控制、锁屏歌词、模糊封面底加正在唱那句的桌面小组件、长按图标的快捷选单、邀请链接直接打开 App、拔耳机自动暂停、主题图标、横屏全屏看歌词、在 App 里直接更新。
- **iPhone**：网页版，可以加到主屏幕。
- **中文 / English**，深色、浅色主题。

目前是**邀请制**：谁都可以先逛逛；要听歌、收藏、建歌单，需要登录并输入成员给你的邀请码。

## 架构

| 部分 | 用到的技术 |
|---|---|
| App 界面（电脑、Android、网页共用） | Vue 3、Pinia、Vue Router、vue-i18n、three.js |
| 电脑版 | Electron + electron-vite，electron-builder（NSIS 安装包） |
| Android | Capacitor |
| 账号和用户数据 | Supabase：Auth（邮箱、GitHub、Google）、带 RLS 的 Postgres、Realtime（一起听）、Storage（头像） |
| 网页版和 Android 的音乐 API | 部署在 Vercel 的网易云音乐 API，只让成员使用 |
| 测试 | Vitest |

歌曲信息、音频和歌词来自网易云音乐（通过社区维护的 API）。"我喜欢、歌单、听歌记录、每日推荐、私人 FM"都存在 LyriStage 自己的 Supabase 数据库，不需要网易云账号。

```
src/main/       Electron 主进程：窗口、托盘、桌面歌词、本地音乐 API
src/preload/    页面和 Electron 之间的桥梁（window.lyristage）
src/renderer/   Vue 界面，电脑版、Android、网页版共用
src/core/       不依赖界面的核心逻辑：请求、网易云接口、歌词、用户数据、推荐算法
server/         部署到 Vercel 的音乐 API（每个请求都先检查是不是成员）
supabase/       数据库迁移
android/        Capacitor 的 Android 项目
```

## 开发

需要 Node.js（开发时用的是 24），做 Android 还需要 Android Studio。

```bash
npm install
cp .env.example .env      # 再填入 Supabase 的网址和 anon key

npm run dev               # 电脑版，会在 127.0.0.1:10754 启动本地音乐 API
npm test                  # 单元测试

npm run api:dev           # 网页版：先开本地音乐 API（3001 端口）
npm run web:dev           # 网页版：http://localhost:5173（同一个 Wi-Fi 的手机也能打开）
```

在 VS Code 的终端启动 Electron，如果报 `Cannot read properties of undefined`，是继承了 `ELECTRON_RUN_AS_NODE=1`，改用 `env -u ELECTRON_RUN_AS_NODE npm run dev`。

### 自己架后端

1. 在 [Supabase](https://supabase.com) 新建项目。
2. 在 SQL Editor 里按顺序执行 [supabase/migrations](supabase/migrations) 的文件：
   `init`（用户数据）、`invites`（邀请制）、`listen_together`、`avatars`、
   `security`（一起听只有房主能广播、更安全的邀请码）、`room_chat` 和 `room_chat_fix`（一起听聊天）、
   `room_handover`（房主转让）、`delete_account`（在设置页删除账号）、`bilibili_picks` 和 `bilibili_picks_grant`、
   `friends_and_shared_playlists` 和 `playlist_people_profiles`（好友、共同歌单）、
   `history_compaction`（每月自动整理旧的听歌记录，要先开启 `pg_cron`）、`slim_play_history`（听歌记录瘦身）、`friends_weekly_board`（好友周榜）、
   `storage_usage_all_databases`、`playlist_covers`（歌单自定义封面）、`archive_old_history`（每月把两年以前的听歌记录搬去 File storage）、`archive_secret_hash`、`app_errors`（错误自动回报给管理员）、`weekly_backup`（每周自动备份到私人的 backups 桶，留最近 8 份；用同一个 Edge Function）、`backup_read_access`、
   `lyric_translations`（共用的英文歌词翻译）、`voice_chat`（一起听语音）、`room_requests_and_listing`（点歌、好友的房间、请求加入）、`room_members`（只有房间里的人看得到房间）、`friend_notes`（便签和表情回应）、`push_notifications`（Android 通知；要另外部署 [supabase/functions/send-push](supabase/functions/send-push) 这个 Edge Function，还要一个 Firebase 项目）。
   `archive_old_history` 和 `weekly_backup`
   还要把 [supabase/functions/archive-history](supabase/functions/archive-history) 部署成 Edge Function（关掉 JWT 验证），
   再把 SQL 文件最下面 `archive_function_url` 那一行换成你的项目代号执行。
3. Authentication → Providers：打开 Email（要 GitHub / Google 登录的话也打开）。
   在 URL Configuration 的 Redirect URLs 加上 `lyristage://auth/callback`（电脑版登录）和 `http://localhost:5173/**`（网页版开发）。
4. 把项目网址和 anon key 填进 `.env`（`VITE_SUPABASE_URL`、`VITE_SUPABASE_ANON_KEY`）。
5. 把 `server/` 部署到 Vercel，环境变量设 `SUPABASE_URL` 和 `SUPABASE_ANON_KEY`，再把 `.env.web`、`.env.app` 的 `VITE_API_BASE` 改成它的网址。

邀请码可以在 App 的**设置 → 邀请朋友**生成（管理员才看得到），也可以在 SQL Editor 里：

```sql
select public.create_invite();               -- 一次性邀请码
select public.create_invite(5, '大学同学');    -- 可以用 5 次
update public.members set is_admin = true where user_id = '…';  -- 设别人当管理员
```

### 打包

```bash
npm run dist:win     # Windows 安装包，输出在 release/
npm run app:apk      # Android debug 版 APK
npm run web:deploy   # 网页版部署到 Vercel
```

正式版 APK 用 `android/keystore.properties` 里写的金钥签名（`storeFile`、`storePassword`、`keyAlias`、`keyPassword`）。这个文件不在仓库里，没有它只能打 debug 版。
