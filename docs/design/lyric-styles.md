# 歌词排版风格

LyriStage 的歌词舞台支持多种排版风格，可以切换。每种风格都使用 `src/core/lyrics` 输出的同一份数据
（行、逐字时间、翻译、罗马音），只是画法不同。

## 风格 A：单行大字 · 动态歌词（参考抖音动态歌词视频）

参考：用户 2026-10-19 提供的截图（抖音 @花予你《沉溺》邹沛沛/Pank，画面中央是"亲吻我的"）。

| 元素 | 参考图里的样子 | 实现思路 |
|---|---|---|
| 一次一行 | 当前句居中、超大字号，占满屏幕宽度 | 只渲染当前行；切行时淡出 / 淡入 |
| 字体 | 粗犷、做旧，像毛笔或老印刷，边缘斑驳 | 免费中文书法字体（Google Fonts：马善政 Ma Shan Zheng、志莽行书 Zhi Mang Xing 等，OFL 授权）+ SVG `feTurbulence` 噪点做纹理遮罩 |
| 残影 | 同一句更大、半透明、模糊地叠在后面 | 同一行复制一层：放大 1.3–1.6 倍、`blur`、低透明度、轻微错位 |
| 逐字浮现 | — | 用逐字时间（yrc 或估算）让每个字按唱到的时间依次出现 |
| 背景 | 插画 / 封面压暗，冷灰绿色调 | 封面图 + 暗化 + 色调滤镜；以后可以支持自定义背景图 |
| 质感 | 全画面颗粒噪点，漂浮的小光点 | 静态噪点叠加层 + 少量粒子（canvas），手机上减少数量 |
| 署名 | 底部小字《歌名》歌手 | 歌名、歌手，小字号，低对比度 |

## 风格 B：滚动歌词（参考 Apple Music）

- 整页歌词上下滚动，当前行放大、高亮，前后行逐渐变淡、模糊
- 当前行逐字高亮（`background-clip: text` 渐变）
- 翻译 / 罗马音显示在原文下面
- 点击某一行跳到那里播放

## 共同要求

- 用 `requestAnimationFrame` 读播放时间驱动，不用定时器轮询
- 只给当前行做逐字动画，其他行是静态的
- 系统开启"减少动态效果"时关闭动画
- 手机上要保持流畅：不在大面积元素上用实时 `filter: blur`
